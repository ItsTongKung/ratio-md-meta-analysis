# Reproducibility guide

This repository reproduces every quantitative result of the article from
deterministic seeds. Two levels are supported.

## Software environment

- Python **3.12** (verified on 3.12.10)
- numpy 2.4.6, scipy 1.17.1, matplotlib 3.10.9, pandas 3.0.3
  (see `requirements.txt`; exact pins reproduce the archived results
  bit-for-bit, including the random streams)

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
```

No compilation is needed; the pipeline is pure Python/NumPy.

## What reproduces what

| Archived artifact | Regenerated by | Agreement expected |
|---|---|---|
| `results/targets/d4_targets.json` | `code/compute_targets.py` | identical numerics (run/stability blocks); the `meta.date`/`meta.seconds` fields record the re-run |
| `results/cell_summaries/*.json` (152) | `code/run_simulations.py` | bit-identical except `wall_s` (wall time) |
| `results/analysis/*` (9 CSVs + `summary.json`) | `code/analyze_results.py` | byte-identical |
| article tables (11 CSVs) | `code/make_tables.py` | byte-identical |
| article figures (5 × PNG + PDF) | `code/make_figures.py` | generated from the archived analysis outputs (deterministic; PDFs differ only in embedded timestamps) |

The article tables and figures are deterministic derived artifacts:
they are generated on demand from the archived analysis outputs and are
deliberately not version-controlled. After generation they appear under
`outputs/tables/` and `outputs/figures/` — a gitignored generated working
directory, not part of the repository contents.

The five article figures are the article's publication figures:

- **Figure 1** — published ratio procedure, coverage of *T₂* across the
  60-cell core grid (source: `results/analysis/H1_primary_coverage.csv`);
- **Figure 2** — finite-sample interval-scale calibration of the published
  ratio procedure (source: `results/analysis/variance_calibration.csv`);
- **Figure 3** — distinct estimands under informative study size
  (source: `results/analysis/estimand_map.csv`);
- **Figure 4** — prespecified plug-in bias correction relative to the
  published ratio procedure (source: `results/analysis/H4_paired_P4_P1.csv`);
- **Figure S1** — sensitivity behavior in informative-size scenario S3
  (source: `results/analysis/sensitivity_summary.csv`).

`make_figures.py` generates exactly these five figures, with the
article's numbering and labels, directly from those CSVs at the fixed
220-dpi canvas. Generation is deterministic: repeated renders produce
byte-identical PNG rasters under the pinned environment, PDF files carry
identical vector content and differ only in embedded creation timestamps,
and `verify_reproduction.py` checks the generated output inventory, the
canvas dimensions, the tolerance-band rendering, and the archived source
data.

## Results-only reproduction (no simulations)

Uses the archived cell summaries and regenerates everything downstream —
analysis outputs, tables, and figures (~1 min, dominated by the
verification re-executions):

```bash
python code/analyze_results.py
python code/make_tables.py
python code/make_figures.py
python code/verify_reproduction.py
```

After the generation steps the article tables appear under
`outputs/tables/` and the figures under `outputs/figures/`.

`analyze_results.py` rewrites `results/analysis/` from
`results/cell_summaries/` and must reproduce the archived files exactly.
If you want to keep the archived analysis untouched, run the three
generation steps in a copy of the repository.

## Full reproduction (all simulations)

Re-runs the complete study: 152 cells, base grid 7,840,000 replications
(≈ 2 min) plus the boundary-precision boost pass over the 32
boundary-band cells (≈ 2 min), then the
results-only steps. The D4 comparator target Monte Carlo is deterministic
(same seeds) and takes ≈ 1 min. Total ≈ 5 min on a desktop CPU
(measured on the prespecified computational environment: targets 45 s, base run 105 s, boost run
119 s, analysis 2 s, tables 3 s, figures 4 s).

```bash
python code/compute_targets.py
python code/run_simulations.py --family all
python code/run_simulations.py --family all --boost "D1,S2,1,10=78670;D1,S2,2,10=87181;D1,S2,2,5=320259;D1,S3,1,10=43282;D1,S3,2,10=22464;D1,S3,2,5=46644;D1,S4,1,10=59516;D1,S4,2,10=233643;D1,S4,2,3=1000000;D1,S4,2,5=27016;D1,S5,1,10=73677;D1,S5,2,10=24999;D2,S1,2,10=1000000;D2,S3,1,10=32252;D2,S3,2,10=90331;D3,S3,1,10=22464;D3,S3,1,5=20639;D3,S3,2,10=37574;D3,S3,2,5=25942;D4,S2,1,10=81362;D4,S2,1,5=134196;D4,S2,2,10=42242;D4,S2,2,5=263467;clamp5,S1,1,10=1000000;clamp5,S3,1,10=220605;clamp5,S3,2,10=299432;core,S2,1,5=159755;core,S2,2,10=416633;core,S2,2,5=619687;core,S3,2,10=1000000;core,S5,1,10=1000000;core,S5,2,10=1000000"
python code/analyze_results.py
python code/make_tables.py
python code/make_figures.py
python code/verify_reproduction.py
```

The `--boost` value above is the exact executed 32-cell list, also
documented in `config/simulation_design.yaml`
(`r_boost.boosted_cells`, columns `cell` and `R_boost`). The boost pass
must run **after** the base pass and writes the final cell summaries
(same seed stream: the first R_base replications are bit-identical and
the boost extends the stream; see `config/seeds.md`).

## Verification

```bash
python code/verify_reproduction.py
```

Works from a fresh clone: the script generates the article tables and
figures into temporary directories and verifies them by scientific
content, so no committed derived artifacts are required. Checks, in
order: the 152 archived cell summaries and static target files against
`results/manifest_checksums.csv`; the target constants (the law constants
of `code/methods.py` against `results/targets/exact_targets.json`, and
the committed D4 comparator target values with their internal two-pass
agreement); the archived analysis outputs against a fresh regeneration
(byte-for-byte); the generation of the 11 tables and the five figures,
each deterministic (two independent generations byte-identical; figure
PNG rasters byte-identical); the headline classification counts and
replication accounting; four selected cells (one per DGM branch)
re-executed from seed and compared to the archived summaries bit-for-bit
(except wall time); the generated tables against the archived scientific
reference values (Table 1 design constants, Table 2 classification
counts, Table 3 estimand tracking against the archived cell summaries,
Table 4 probe results, Tables S1–S7 row counts and headers); and the
generated figures against the article geometry (output inventory,
220-dpi canvas dimensions, tolerance-band rendering, and the archived
source data). The script exits nonzero on any material mismatch.

Runtime of the verification script itself: ≈ 1 min (dominated by the four
re-executed cells). After a full re-run, the cell-summary checksums differ
(the wall-time field changes) — the script reports this as an expected
warning and validates the regenerated content instead.

## Notes

- The archived cell summaries contain a `wall_s` field (execution wall
  time); it is excluded from every comparison.
- `results/targets/d4_targets.json` records its generation date and wall
  time in `meta`; the numeric blocks (`run1`, `run2`, `stability`) are what
  must match.
- Random streams: PCG64 via `numpy.random.default_rng`; seed design in
  `config/seeds.md`.
